# 🛣️ Engineering Roadmap

My long-term technical trajectory — building on existing expertise in distributed systems and Go to architect enterprise-scale, cloud-native platforms.

---

## 📅 The 2026–2030 Arc

### 2026: Deepen Distributed Systems Mastery
* **Target:** H2 2026
* **Focus:** Kubernetes, Service Mesh, Advanced gRPC Patterns
* **Goals:**
  * Migrate production microservices from Docker Compose to **Kubernetes (K8s)** with Helm charts.
  * Implement distributed tracing using **OpenTelemetry and Jaeger** across the NATS + gRPC service mesh.
  * Explore advanced **gRPC streaming** (bidirectional, server-streaming) patterns in production.
  * Achieve the **AWS Solutions Architect Associate** certification.

### 2027: Cloud-Native Architecture & Open Source
* **Target:** Full Year 2027
* **Focus:** Cloud-native SaaS, Open Source Contributions
* **Goals:**
  * Architect a fully cloud-native SaaS product on AWS with ECS/EKS, RDS, ElastiCache (Redis), and CloudFront.
  * Contribute to open source Go ecosystem projects — API Gateway tooling, gRPC middleware libraries.
  * Build and release a public **Golang microservices starter kit** with gRPC, NATS, Kong, and Docker baked in.

### 2028: DevSecOps & Observability Integration
* **Target:** Full Year 2028
* **Focus:** Security-first architecture, Full Observability Stack
* **Goals:**
  * Integrate automated security scanning (building on CompliSec architecture) into CI/CD pipelines.
  * Master **Terraform** for declarative infrastructure-as-code across AWS environments.
  * Build full observability: metrics (Prometheus/Grafana), tracing (Jaeger), logging (Loki).

### 2030: Principal / Staff Engineer
* **Target:** 2030
* **Focus:** High-Availability Systems, Engineering Leadership
* **Goals:**
  * Architect systems capable of handling millions of concurrent users with sub-100ms P99 latency.
  * Lead large-scale engineering teams and define system-wide technical standards.
  * Mentor junior engineers and contribute to core Go/cloud-native open source projects.
