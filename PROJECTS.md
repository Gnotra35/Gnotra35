## 1. ⚙️ GRC Distributed Monolith

A production-grade distributed system supporting independently deployable services with modular scaling boundaries.

- **Stack:** Golang · gRPC · NATS JetStream · Kong API Gateway · React.js · TanStack Query
- **Key Features:**
  - **10+ Independent Services:** Designed modular scaling boundaries enabling isolated deployments per service domain.
  - **Strongly-Typed gRPC:** Implemented strongly-typed gRPC service definitions for inter-service communication, reducing serialization overhead by **30%** compared to REST.
  - **NATS Event Queue:** Integrated NATS message queue for event-driven workflows across 6+ services, achieving full producer-consumer decoupling and improved fault tolerance.
  - **Kong API Gateway:** Configured as a unified entry point with JWT authentication and rate limiting, securing **100% of externally exposed endpoints**.
  - **React Dashboard Integration:** Architected RESTful endpoints integrated with a React dashboard via TanStack Query for real-time data synchronization.
